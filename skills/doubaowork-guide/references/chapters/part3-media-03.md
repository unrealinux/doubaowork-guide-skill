# 同一份内容，怎么改成每个平台自己的版本

做内容的人大概都干过这种事：公众号文章刚写完，老板说“小红书也发一下”；过一会儿又补一句，“知乎和视频号顺手也做了吧”。

听着像复制粘贴，真做起来却很费时间。公众号讲究把一件事说透，小红书要一张图就能马上看懂，讲什么，知乎读者更关心“为什么”，视频号则要在几十秒里把冲突讲出来。同一篇稿子直接搬过去，要么太长，要么太生硬，或者一开口就像在念文章。

这次我在豆包工作里连续跑了四个任务：做小红书图文、拆成一周内容、改成四个平台原生稿，最后再做一次发布前审核。这套生产线如下：

```text
同一份事实包
→ 先判断平台的特点
→ 再规定每个平台的交付格式
→ 生成草稿
→ 打开成果逐段检查
→ 发布前统一审核
```

## 选对工具：这篇其实只需要两个 Skill

| 任务 | 最优工具 | 为什么 |
|-|-|-|
| 小红书图文、7 天拆分、四平台原生稿 | 多平台改写分发 | 它本来就负责把同一份内容改成不同平台的结构和语气 |
| 发布前总检查 | 营销素材审核 | 它能同时查日期、数字、链接、来源、隐私和绝对化表达 |
| 真正生成小红书卡片视觉 | 创意设计（可选） | 本次只交付卡片文案和版式建议，没有为了显得复杂额外叠工具 |

这次没有加链接器或专家团。原因是：专用 Skill 已经能完整覆盖任务。工具不是越多越专业，链路越长，反而越容易让事实边界在中间丢掉。

## 任务一：小红书图文，不能只把长文切成九张图

### 第一步：先选「多平台改写分发」

在新任务里调用「多平台改写分发」。这一步看着普通，却决定了后面是在重新设计一篇小红书笔记，还是只把长文机械切片。

![图03-01 先选择多平台改写分发](https://doubaowork.homes/media/PePCwvBv-01-f7d660b9cad1.png)

### 第二步：提示词里先写事实，再规定交付物

我给它的材料只有 5 条已经确认的事实：本次实测对象和日期、事实包写作法、事实与判断要分开、AI 能做什么、发布前仍要人工复核。同时明确不能虚构亲身经历、阅读量、收入和客户案例。

交付格式：3 个标题、8 页卡片、300 字以内正文、8 个以内话题标签，再加发布前人工复核清单。

```text
6. 最后单列“发布前人工复核清单”；
```

## 任务三：同一份事实包，改成每个平台自己的版本

前两个任务解决了“小红书怎么做”和“一周怎么拆”。第三个任务才是真正的一稿多发：同一份内容，分别生成微信公众号、小红书、知乎和视频号四个版本。

![图03-09 多平台版本选择技能](https://doubaowork.homes/media/PePCwvBv-09-854bac3150e1.png)

平台名只是起点，还要把每个平台最终交什么写清楚：公众号约 800 字，小红书 6 页卡片加 250 字正文，知乎约 900 字，视频号是一份 60 秒口播稿。四份稿子共享同一个内容，但可以改变切入角度、顺序、语气和互动方式。

我还要求每个版本后面补一行“保留了什么、删掉了什么、为什么这样改”。这能逼着 AI 把改写逻辑说出来，方便编辑检查。

#### 可直接复制的实测提示词

```text
请使用“多平台改写分发”能力，把共用事实包分别改写成四个平台自己的原生版本，并先给出平台策略表。

【素材】请在这里粘贴你的共用事实包，或上传事实包文件。

交付：
- 微信公众号：约 800 字，完整讲清三步方法、AI 边界和行动建议；
- 小红书：6 页卡片提纲 + 约 250 字正文，重收藏和复核清单；
- 知乎：约 900 字，以问题开头，有反例、论证和争议收尾；
- 视频号：60 秒口播稿，冲突开场、三步骨架、一句话结论，注意口语节奏。

四个版本只能使用共同事实包。可以改变角度、顺序、结构和语气，不能改变事实、日期、限制条件。每个版本后标注“保留事实 / 删掉信息 / 为什么改”。最后给四平台人工复核清单。只生成草稿，不安排发布。
```

## 记住这套提示词公式

以后你要把一份内容改到任何平台，提示词至少写清五件事：

1. **共同事实包**：哪些事实已经确认，来源、时间和限制是什么；
2. **目标读者**：这条内容到底写给谁；
3. **平台交付格式**：不是只给平台名，而是给字数、卡片数、口播时长和结构；
4. **允许改变与禁止改变**：角度、顺序、语气可以改，事实、数字和证据边界不能改；
5. **人工复核和发布边界**：只生成草稿，发布前检查日期、数字、链接、引用、版权和敏感表达。

发布前，再用这张清单走一遍：

- [ ] 四个平台使用的是不是同一份事实包  

- [ ] 有没有为了适配平台，顺手改坏数字、时间或条件  

- [ ] 每个平台的结构是不是符合真实阅读动作  

- [ ] 链接是否可打开，引用和图片是否有来源  

- [ ] 有没有绝对化、虚假承诺、隐私或版权风险

- [ ] 最终交付物是否已经重新打开验收

一稿多发真正省下来的是不用每到一个平台都重新想一遍“我到底该怎么改”。事实包守住不变的部分，平台策略决定应该改变的部分，最后再用统一审核把风险兜住。

这才像一条能交给朋友、能反复复用的内容生产线。
