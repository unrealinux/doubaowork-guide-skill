# API 服务和连接器，到底该怎么选？

这两个功能容易混淆，我来给大家说明一下。

你在自己的网站或应用里调用豆包大模型，用API 服务；

![](https://doubaowork.homes/media/ExsfwA8V-01-4a162bcbb63e.png)

你想让豆包工作读取飞书、网页或其他业务系统，用连接器。

![](https://doubaowork.homes/media/ExsfwA8V-02-3730b999d791.png)

## API 服务适合开发者

从豆包工作头像菜单进入“API 服务”，会跳到火山引擎的开发者页面。模型名称、价格和接入方式可能更新，具体以当时的官方控制台和文档为准。
