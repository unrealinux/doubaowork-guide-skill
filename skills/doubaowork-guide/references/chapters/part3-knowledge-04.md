# 老同事的经验别让它躺平！我用豆包工作把飞书知识库变成了可复用Skil

把经验文档整理成可复用的 Skill，可以减少重复整理，让团队经验更容易传播，也方便 Agent 在实际任务中调用。本节以一个用于小红书运营的飞书知识库为例，介绍如何使用豆包工作将其中的经验文档制作成 Skill，并结合操作记录展示实际效果。

> 前置条件：保证豆包登录的账号和你要使用的飞书知识库保持一致。

## 打造经验 Skill 的实操

言归正传，继续收敛讲解我们的知打造经验skill的事情。

### 先盲问：知识库能不能看到

开始制作 Skill 前，我先确认豆包工作能否读取目标知识库，输入以下提示词。

> 你帮我看看 小红书运营知识库 能看到吗

![](https://doubaowork.homes/media/Cnpbwr9A-05-485572f6726f.png)

结果真如上图可以看到，下面就是打造经验skill。由于一开始还没有明确的结构方案，我先让豆包工作根据知识库内容给出建议。

### 让豆包设计Skill 结构

> 将这个这个小红书运营知识库     把这份经整理成一个  小红书运营 skill，将里面的知识融合到 skill 里面去，你会怎么写这个 skill

![](https://doubaowork.homes/media/Cnpbwr9A-06-8c8886e66517.png)

> **定位**：现有 skills 里已有 `doubao-newmedia-writing`（负责小红书图文 / 短视频的**内容创作**）。这个新 skill 应该避开重复，定位为**运营全链路的方法论与 SOP**—— 当用户问起号、定位、选题、标题封面、涨粉、变现、引流、开店、投放、违规申诉这类 "运营怎么做" 的问题时触发，输出基于你知识库沉淀的结构化方法。

这个定位符合我的预期。明确 Skill 的职责边界后，下一步继续设计它的目录结构。

### Skill 目录结构

豆包工作会将Skill目录进行拆分，如下图。

![](https://doubaowork.homes/media/Cnpbwr9A-07-8c7759b56944.png)

放大看看这个结构，这个 Skill 由 `SKILL.md` 主文件和 `references` 资料目录组成，主文件负责判断触发条件、选择处理路径并组织工作流。`references` 按起号定位、平台机制、内容创作、涨粉运营、变现商业化、引流与合规六个主题分类。

```Python

    │   ├── 收录与搜索.md           # 收录机制、关键词优化提高排名（运营系统课1.3、2.4、爆文逻辑10）
    │   └── 限流与规则.md           # 限流6个坑及解决方案、平台规则、降权应对（爆文逻辑11、运营系统课1.2）
```
