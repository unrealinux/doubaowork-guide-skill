# 从临时调研到交付正式报告，临时汇报不用愁

临时接到一个调研任务，时间紧、题目大，往往比找资料本身更麻烦。网页越开越多，数字又来自不同年份，等到开始做汇报，手里有一堆材料，却讲不清到底该得出什么结论。

这次调研要帮谁做决定，哪些来源能用，最后交一份文档还是一套 PPT？

先把这几件事定下来，再让豆包工作去检索、精读和整理，后面的页面才不会反复推倒重来。

一份能用于汇报的调研，需要同时处理四件事。研究问题要服务一个具体决策，资料要能追溯，结论要有证据，页面还要让读者快速看懂。只完成其中一项，最后都很难直接拿去开会。

比较稳妥的顺序是先确定范围和验收条件，再收集与核验材料，随后形成结论和证据对应表，最后制作 PPT。视觉优化放在内容确认之后，能减少反复返工。

## 提示词模版

这份模板适合临时接到一个陌生题目时使用。填写方括号之前，先确认这次调研要支持什么决定，谁会阅读，时间和地区范围到哪里为止。问题越具体，检索范围越容易收住。

来源要求和交付要求也应当一起写进任务。前者约束事实质量，后者决定最终页面怎样组织。若时间很紧，可以减少问题数量和页数，关键数据的出处仍要保留。

```text
请围绕“【调研主题】”开展深度调研，并生成一份面向【目标读者】的PPT报告。
本次调研用于支持【具体决策】，研究范围包括【地区范围】，重点关注【核心问题】，信息时间范围为【开始时间】至【截止时间】。
请先阅读全部附件，再搜索公开资料进行补充。优先使用政府部门、企业官网、财报、监管文件、学术论文和权威研究机构资料。
对市场规模、增长率、公司经营数据、产品价格、政策规定和时间节点等重要事实，必须标明来源和发布日期。每个关键结论尽量使用两个独立来源进行交叉验证。
请明确区分：
- 来源中直接说明的事实；
- 根据多个事实形成的分析判断；
- 缺少充分证据的假设。
不要编造市场数据、公司数据、客户案例或来源。不同来源数据存在冲突时，请展示差异并解释可能原因。
PPT控制在【15～20】页，建议包含：执行摘要、研究范围、市场概览、关键数据、竞争格局、用户需求、趋势判断、风险、战略建议、行动计划和来源附录。
每页只表达一个主要观点，标题使用结论式表达。尽量使用图表、对比矩阵、时间线和流程图表达信息，避免整页大段文字。
所有图表都需要注明数据来源、统计口径和时间。最后附完整来源清单，包括资料名称、机构、发布日期和网页链接。
请同时输出：
- 完整PPT；
- 一页管理层摘要；
- 关键结论与证据对应表；
- 调研中仍未确认的问题清单。
```

## 以WorkAgent调研为例

这个例子把市场进入、客户选择、产品定位和路线图放进同一项任务，研究问题因此能够围绕管理层决策展开。中国市场是重点，海外材料用于比较，时间范围也写得很清楚。

结果生成后先看关键结论与证据能否逐项对应，再检查市场数据、公司信息和产品能力的发布日期。

```Markdown
请围绕“Work Agent行业研究”开展深度调研，并生成一份专业的PPT报告。

一、研究信息
研究主题：Work Agent行业研究
目标读者：公司管理层、战略负责人和产品负责人

需要支持的决策：
1. 判断Work Agent市场是否值得进入
2. 选择优先服务的客户和应用场景
3. 确定产品定位和差异化方向
4. 制定未来12至24个月的产品路线图

研究区域：以中国市场为重点，同时参考海外市场。

研究时间：研究2023年至2026年的发展情况，并分析未来3年的发展趋势。

二、重点研究问题
请重点回答：
1. Work Agent是什么？与AI助手、Copilot和RPA有什么区别？
2. 当前市场处于什么发展阶段？
3. 中国及全球市场的发展空间如何？
4. 国内外有哪些代表性公司和产品？
5. 不同产品的定位、功能和目标客户有什么差异？
6. Work Agent适合应用在哪些工作场景？
7. 企业客户最关注哪些产品能力？
8. 当前行业面临哪些技术、安全和商业风险？
9. Work Agent未来3年可能出现哪些趋势？
10. 新进入者应该选择什么产品和市场策略？

三、外部调研要求
请结合公开资料补充和核验附件内容。
优先参考：
1. 企业官网及官方产品资料
2. 政府、行业协会和研究机构
3. 上市公司财报及公开材料
4. 学术论文和权威市场报告
5. 可信的科技及行业媒体
关键数据需要标注来源、发布时间和网页链接。
请区分事实、分析判断和行业预测。无法核实的信息标注“待核验”，不要编造数据或案例。

四、PPT要求
请生成一份15至18页的中文PPT，页面要求
1. 每页突出一个核心观点
2. 标题尽量直接表达结论
3. 避免堆积大段文字
4. 优先使用图表、对比表、矩阵和时间轴
5. 图表需要标注数据来源和时间
```

**执行过程**系统先读取附件和任务范围，再补充公开资料，核对关键数字与时间。随后把事实、分析判断和待核验信息分别整理，并据此生成报告页面。
