## 数据清洗与标准化

数据清洗需要先定义什么算正确。空格、地区写法、数值格式和重复记录都有明确规则，模型才有依据处理。无法确定的内容放进问题数据，比自动猜一个值更便于追溯。

```Markdown
请清洗我上传的《2026年1月销售明细.xlsx》。

请保留原始工作表不变，新建“清洗后数据”和“问题数据”两个工作表。

清洗规则：
1. 删除文本字段前后的空格。
2. 将“华 东”“ 华东”等写法统一为“华东”。
3. 将销售数量、销售单价转换为数值。
4. 将折扣率统一转换为小数，例如 10% 应保存为 0.1。
5. 完全重复的记录只保留一条。

不要擅自补全无法确定的数据。
```

这份样例里同时存在多余空格、地区写法不一致、数值格式混乱和重复记录。

## 多个 Excel 合并操作

合并有两种常见方向，纵向合并、横向合并。

多个 Excel 纵向合并，把本地的2026年1月至4月销售明细文件合并，

```Markdown
请合并文件中2026年1月至4月销售明细文件。

处理要求：
1. 按字段名称匹配列，不要只根据列的位置合并。
2. 将所有明细追加到一个名为“销售总表”的工作表。
3. 新增“来源文件”和“来源工作表”两列。
4. 检查各文件是否缺少字段或存在多余字段。
5. 根据订单编号检查重复记录。
6. 不要直接删除存在冲突的重复订单，将其放入“合并异常”工作表。
7. 新建“合并摘要”，列出每个文件的原始行数、有效行数和异常行数。
8. 最终输出《2026年1-4月销售合并表.xlsx》。
```

## Excel数据分析

通过公式增加新列操作，

```Markdown
请在2026年1-4月销售合并表_关联产品客户.xlsx中新增以下计算列：

1. 销售额 = 销售数量 × 销售单价 ×（1 - 折扣率）
2. 成本金额 = 销售数量 × 单位成本
3. 毛利额 = 销售额 - 成本金额
4. 毛利率 = 毛利额 ÷ 销售额
5. 价格偏差率 =（销售单价 - 标准售价）÷ 标准售价

要求：
1. 使用 Excel 公式，不要把计算结果写成固定数值。
2. 销售额、成本金额、毛利额保留两位小数。
3. 毛利率和价格偏差率显示为百分比。
4. 销售额为0时，毛利率显示为空白，不要产生除零错误。
5. 使用统一的公式结构填充全部数据行。
6. 对毛利率小于10%的订单使用红色条件格式。
```

**执行过程**系统把统一公式填充到全部数据行，并设置金额、百分比和低毛利订单的条件格式。

数据透视与经营汇总，

```Markdown
请根据2026年1-4月销售合并表_关联产品客户.xlsx创建“经营分析”工作表。

需要统计：
1. 各月份的销售额、毛利额、订单数和毛利率。
2. 各区域的销售额、毛利额和客户数量。
3. 各产品分类的销量、销售额和毛利额。
4. 各销售渠道的销售额占比。
5. 各销售人员的销售额排名。

要求：
- 订单数按不同订单编号统计。
- 客户数量按不同客户编号统计。
- 毛利率使用“毛利额合计 ÷ 销售额合计”，不要直接平均明细毛利率。
- 添加总计。
- 金额使用千位分隔符。
```
