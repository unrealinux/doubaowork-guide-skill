# 豆包工作常用指令模板，随手复制就能用

在豆包工作中新建“工作任务”，粘贴下面的模板，再补充文件、链接、时间范围和输出位置。涉及多个文件时建议先创建项目；涉及外部系统时先确认所需连接器已经授权；涉及移动、覆盖、发送或发布时，保留人工确认。

## 文件整理

```text
请先读取我提供的文件夹，统计文件类型、数量和重复项。
按照文件类型和主题给出新的文件夹结构与重命名规则。
先输出整理方案和预计改动清单，等我确认后再移动或重命名文件。
不要删除任何文件；遇到同名文件时停止并询问。
```

## Excel 分析

```text
请分析我提供的 Excel 文件。
先检查工作表、字段、缺失值和异常值，再输出核心指标、趋势变化、可能原因和建议行动。
请生成摘要报告和必要图表，并说明每个结论对应的数据范围。
不要修改原文件，把结果保存为新文件。
```

## PPT 生成

```text
请根据这份 Word 文档生成一份 10 页左右的 PPT。
每页包含标题、3-4 个要点和建议图表；所有数据与结论都应来自原文。
风格正式，适合管理层汇报。
先给出页面大纲，确认后再生成完整文件。
```

## 会议纪要

```text
请整理这段会议内容。
输出会议结论、待办事项、负责人、截止时间、风险点和未决问题。
没有明确负责人或截止时间时标记“待确认”，不要自行补写。
重要结论尽量保留对应原话或时间位置，方便复核。
```

## 行业调研

```text
请调研【行业 / 公司 / 产品】，时间范围为【】。
输出市场背景、主要参与者、竞品对比、趋势、机会和风险。
每条关键事实保留来源链接和发布日期；来源之间存在冲突时并列说明。
无法确认的信息标记“待核验”，不要编造。
```

## 定时简报

```text
请创建一份“每日行业简报”的任务说明。
每天【时间】汇总过去 24 小时的【主题】信息，最多 10 条。
每条包含标题、摘要、来源、发布时间和链接；重复事件合并。
来源不足时说明缺失情况，不要为了凑数编造。
先在普通工作任务中运行一次，确认结果后我再到“定时任务”中保存。
```

## 使用工作伙伴或小队

```text
目标：【要完成的交付物】
资料：【项目、文件或链接】
希望由【工作伙伴 / 工作小队】完成。
请先说明分工、交接产物和需要我确认的节点，再开始执行。
未经确认不得对外发送、发布或覆盖正式文件。
```
