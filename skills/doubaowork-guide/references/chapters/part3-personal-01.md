# 收件箱很满，先找出今天必须处理的事

每天一打开邮箱，未读邮件往往已经堆了不少。工作通知、项目进展、协作请求和各种抄送混在一起，一封封查看、一件件判断，不仅很费时间，也很容易漏掉真正紧急的事项。

哪些邮件必须今天回复，哪些可以稍后处理，哪些只需知会？

与其在收件箱里来回翻找，不如先让豆包工作帮你排出优先级、划分处理时间窗口，把注意力留给真正需要行动的事情。

## 通过连接器赋予操作权限

连接邮箱以后，豆包工作 才能读取真实邮件并执行搜索或整理。

点击“技能·连接器·伙伴”，找到网易邮箱，点击“+”

![](https://doubaowork.homes/media/IBt2wFwj-01-0a8eb3258ee7.png)

进行邮箱授权，邮箱就是你自己想操作的邮箱，邮箱授权码点击“[网易邮箱客户端授权码说明](https://help.mail.163.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2a5feb28b66796d3b)”内容进行学习操作

![](https://doubaowork.homes/media/IBt2wFwj-02-364e5dc3f3c2.png)

授权完成后，展开能力列表，确认读取、搜索和发送等操作是否已经可用。

![](https://doubaowork.homes/media/IBt2wFwj-03-f443f9b7f0cf.png)

正式整理收件箱前，先读取少量邮件，确认账号、文件夹和时间范围都正确。测试没有问题，再继续做分类和日报。

![](https://doubaowork.homes/media/IBt2wFwj-04-47f38f15815c.png)

## 收件箱形成日报

日报的价值在于把一整页邮件变成几项能行动的判断。可以通过五类进行汇总结果。有额外需求可以单独提出要求。

```Plain Text
读取最近7天内收到的邮件。
按今天必须处理、本周处理、等待他人、仅供知会、疑似风险五类整理。
```

提交提示词后，系统会读取最近七天的邮件，并按照行动时间和处理状态分成五类。这个阶段只做整理，不发送，也不修改原邮件。

![](https://doubaowork.homes/media/IBt2wFwj-05-4d8d0a97fc1b.png)

**因为**这个账号近期几乎没有邮件，因此结果很短。空结果也能验证连接器是否正常读取，以及时间范围和分类规则有没有生效。

![](https://doubaowork.homes/media/IBt2wFwj-06-505b24822f81.png)

连接器也支持发送邮件。工作邮件涉及措辞、收件人、附件和承诺时间，建议先生成草稿，确认无误后再发送。
