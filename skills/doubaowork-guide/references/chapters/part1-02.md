# 豆包工作的下载、安装和登录

## 从官方入口下载

打开豆包工作官网 [https://www.doubao.com/work](https://www.doubao.com/work)，点击“下载豆包工作”，根据系统和芯片选择安装包。

![](https://doubaowork.homes/media/LQNywCHd-01-8ba91f789614.png)

Mac 用户不确定芯片时，点左上角苹果菜单里的“关于本机”；Windows 用户可以在“设置—系统—系统信息”里查看。

![](https://doubaowork.homes/media/LQNywCHd-02-ee94eb113bce.png)

***切记：从官方入口进入下载，不从网盘或不明镜像获取安装包。***

## macOS 安装

打开下载得到的 DMG 安装镜像，将“豆包工作”拖入“Applications（应用程序）”文件夹。

![](https://doubaowork.homes/media/LQNywCHd-03-bdd97fa5c014.png)

安装完成后，从“应用程序”中启动豆包工作。

## Windows 安装

在官网下载菜单中选择适合设备的 Windows 版本，下载完成后双击安装文件。

![](https://doubaowork.homes/media/LQNywCHd-04-53705f12a43c.png)

如系统弹出安全提示，点击运行。

![](https://doubaowork.homes/media/LQNywCHd-05-92a6fce974f3.png)

按安装向导完成安装，然后从开始菜单或桌面启动豆包工作。

![](https://doubaowork.homes/media/LQNywCHd-06-331fb439f58a.png)

![](https://doubaowork.homes/media/LQNywCHd-07-5024fa4c385a.png)

首次启动后，按页面引导登录。

![](https://doubaowork.homes/media/LQNywCHd-08-6214f84038a4.png)

## 登录

首次启动豆包工作后，支持手机号登录、以及飞书账号登录

![](https://doubaowork.homes/media/LQNywCHd-09-33b9a24dc8f5.png)

注意，不同登录方式直接是隔离的，也就是相互不影响。

## 更新

点击左下角个人头像，在菜单中选择“检查更新”。如检测到新版本，按页面提示完成更新。

![](https://doubaowork.homes/media/LQNywCHd-10-7364fb178bd9.png)
